# Contributing

Harborline is not currently accepting outside contributions or pull requests.

The project will update this file if the policy changes after the first release and a separate decision to accept outside contributions.

For usage help or a bug report, follow [SUPPORT.md](SUPPORT.md).

## Maintainer work

Keep shared Toolbox behavior behind module interfaces and OS-specific behavior in named host projections.

Preserve installed-user identities and data paths unless a separate migration decision and rollback test approve a change.

Do not create an empty Linux implementation for symmetry.
